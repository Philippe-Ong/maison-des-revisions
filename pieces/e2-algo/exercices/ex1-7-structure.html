Concept de base

L'exercice repose sur la structure tm du fichier <time.h>, qui décompose le temps en composants lisibles :

struct tm {
    int tm_sec;   /* secondes : 0-59 */
    int tm_min;   /* minutes : 0-59 */
    int tm_hour;  /* heures : 0-23 */
    int tm_mday;  /* jour du mois : 1-31 */
    int tm_mon;   /* mois : 0-11   ← 0 = janvier */
    int tm_year;  /* années depuis 1900 ← 2026 = 126 */
    int tm_wday;  /* jour de la semaine : 0=dimanche ... 6=samedi */
    int tm_yday;  /* jour depuis le 1er janvier : 0-365 */
};

Deux fonctions pour remplir cette structure :

  • time(NULL) → retourne le temps actuel sous forme d'un time_t (nombre de secondes depuis 1970).
  • localtime(&variable) → transforme ce time_t en une structure tm.
✦

a) Date et heure actuelles

time_t maintenant = time(NULL);          /* on récupère le temps actuel */
struct tm temps_actuel = *localtime(&maintenant); /* on le décompose */

printf("Current date and time is : ");
printf("%02d.%02d.%04d %02d:%02d:%02d\n",
       temps_actuel.tm_mday, temps_actuel.tm_mon + 1, temps_actuel.tm_year + 1900,
       temps_actuel.tm_hour, temps_actuel.tm_min, temps_actuel.tm_sec);

On demande l'heure au système puis on la "découpe" avec localtime(). Ici l'affichage est direct avec printf (la fonction AfficherTemps() ne sera utilisée qu'à partir de c).

À retenir

À retenir : tm_mon commence à 0 (janvier = 0) → tm_mon + 1. tm_year est compté depuis 1900 → tm_year + 1900.

✦

b) Le dépassement (overflow) de time_t

Cœur théorique de l'exercice. Le type time_t est une variable 32 bits signée. Sa valeur maximale est :

INT_MAX = 2 147 483 647

Au-delà, la variable déborde (devient négative) : c'est l'overflow du siècle (le « Y2038 problem »). On calcule la date correspondante :

time_t max_time_t = (time_t)INT_MAX;   /* plus grande valeur possible */
struct tm temps_overflow = *localtime(&max_time_t);

printf("Overflow will occur 1s after: ");
printf("%02d.%02d.%04d %02d:%02d:%02d\n",
       temps_overflow.tm_mday, temps_overflow.tm_mon + 1, temps_overflow.tm_year + 1900,
       temps_overflow.tm_hour, temps_overflow.tm_min, temps_overflow.tm_sec);

On utilise la constante INT_MAX de <limits.h>. L'affichage est là aussi direct avec printf. Résultat : 19.01.2038 04:14:07.

✦

c) Fonction d'affichage

Au lieu de mettre printf partout dans main(), on centralise l'affichage dans une fonction :

void AfficherTemps(const char *texte, struct tm temps)
{
    printf("%s" DATE_FORMAT "\n",
           texte,
           temps.tm_mday, temps.tm_mon + 1, temps.tm_year + 1900,
           temps.tm_hour, temps.tm_min, temps.tm_sec);
}
  • texte = le préfixe (ex. « Current date and time is : »), passé en %s
  • temps = la structure tm à afficher (transmise par valeur)
Piège

Piège à éviter : DATE_FORMAT commence par %02d (des int). Il ne faut jamais passer texte (un char *) à une conversion %d. On ajoute donc un %s devant : "%s" DATE_FORMAT. La macro DATE_FORMAT (%02d.%02d.%04d %02d:%02d:%02d) centralise le format des date/heure.

Cela rend main() plus lisible et permet de réutiliser la même chose à plusieurs endroits. Bonne pratique : une tâche = une fonction.

✦

d) Nom du jour de la semaine

La structure ne donne qu'un nombre (tm_wday) : 0 = dimanche, 1 = lundi… Il faut le traduire en mot. Un tableau de noms fait office de table de correspondance :

const char *NomDelSemaine(int jour_semaine)
{
    static const char *const noms[] = {
        "Sunday", "Monday", "Tuesday", "Wednesday",
        "Thursday", "Friday", "Saturday"
    };
    return noms[jour_semaine];
}

L'index du tableau correspond au numéro du jour (0 → dimanche, …, 6 → samedi). main() appelle donc NomDelSemaine(temps_actuel.tm_wday) pour afficher le mot correspondant.

✦

Les pointeurs (focus)

L'exercice est riche en pointeurs alors qu'il semble simple. C'est le bon moment pour bien comprendre ce que veut dire « passer une adresse ».

1. Idée de base

Un pointeur est une variable qui contient l'adresse d'une autre variable en mémoire. En C, on écrit le type suivi d'* :

int nombre = 42;
int *ptr = &nombre;   /* ptr contient l'adresse de nombre */

*ptr        /* contient la valeur pointée → 42          */
&nombre     /* l'adresse de nombre   (= ptr)                */
  • & = « adresse de » (récupère l'adresse).
  • * devant un type = « pointeur vers » (int *).
  • * devant une variable = « valeur pointée » (déréférencement).

Rappel visuel :

        +---------+              +--------+--------+
nombre  |  42     |   ptr ────►  | adresse | valeur |
        +---------+              +--------+--------+

2. Pourquoi localtime() renvoie-t-elle une structure et pas une adresse ?

time_t maintenant = time(NULL);
struct tm temps_actuel = *localtime(&maintenant);
  • time(NULL) : le NULL (pointeur nul) dit « je n'ai pas de fichier à ouvrir », c'est juste un signal. La fonction renvoie le temps par valeur.
  • localtime(&maintenant) : on passe l'adresse de maintenant (&maintenant). localtime lit cette adresse et remplit la structure tm qu'elle renvoie.
  • *localtime(...) : localtime renvoie un pointeur vers une structure interne. Le * (déréférencement) récupère la structure elle-même, qu'on stocke dans temps_actuel.
À retenir

À retenir : & place une adresse dans un appel, * récupère la valeur pointée à un retour. Ici : localtime(&x) puis *localtime(&x).

3. Passer une structure à une fonction : par valeur ou par adresse ?

Deux manières légales d'écrire AfficherTemps :

/* (i) par valeur — COPIE la structure */
void AfficherTemps(const char *texte, struct tm temps) { ... }
AfficherTemps("", temps_actuel);

/* (ii) par adresse — pas de copie, on pointe */
void AfficherTemps(const char *texte, const struct tm *pts) { ... }
AfficherTemps("", &temps_actuel);
  • Par valeur (choix du code) : main copie temps_actuel dans la fonction. Simple, mais la structure est copiée à chaque appel.
  • Par adresse (struct tm *pts) : on passe l'adresse, la fonction lit les champs avec pts->tm_mday (ou (*pts).tm_mday). Plus rapide, et on peut modifier la structure si on le souhaite.

Le code utilise la version par valeur : plus lisible pour un petit exemple, au prix d'une copie.

4. const char *texte : que signifie cette ligne de types ?

Lisez toujours de droite à gauche :

const char *texte;
  • *texte : texte est un pointeur.
  • const char : il pointe vers des char constants (qu'on ne peut pas modifier).
  • Donc : « texte pointe vers des caractères en lecture seule ».
À retenir

Pourquoi const ? AfficherTemps n'a qu'à afficher le texte, pas à le changer. On le précise avec const pour interdire la modification et accepter aussi bien une variable qu'une chaîne littérale ("", « Monday »).

Astuce de lecture : le const modifie ce qui est juste à sa gauche, mais s'il est en tout premier, il modifie ce qui est à sa droite. const char * et char *const ne sont pas pareils :

const char *p;   /* pointeur vers char constant → on ne modifie PAS le texte */
char *const p;   /* pointeur constant → on ne modifie PAS l'adresse */

5. const char *const noms[] : double protection

static const char *const noms[] = { "Sunday", "Monday", ... };
  • noms[] : un tableau de pointeurs.
  • const char * : chaque élément pointe vers un char constant (les noms ne sont pas modifiables).
  • ... *const noms : le tableau lui-même est constant (on ne peut ni changer un nom, ni réaffecter le tableau).
  • static : le tableau est créé une seule fois et reste valide même après le retour de la fonction (contrairement à un tableau local normal).
À retenir

C'est pourquoi NomDelSemaine peut renvoyer un pointeur vers un de ces noms : ils restent en mémoire. Sans static, les noms auraient été détruits à la fin de la fonction → fuite / comportement indéfini.

6. NomDelSemaine renvoie un pointeur

const char *NomDelSemaine(int jour_semaine) {
    static const char *const noms[] = { ... };
    return noms[jour_semaine];   /* renvoie l'ADRESSE du nom */
}
  • Le type de retour est const char * : la fonction renvoie l'adresse d'un nom, pas le nom lui-même.
  • printf("%s", NomDelSemaine(...)) lit le texte à cette adresse.
  • static + const garantissent que l'adresse renvoyée reste valide.

Récapitulatif des pointeurs dans le fichier

Élément Rôle du pointeur
time(NULL) NULL = signal « aucun fichier »
localtime(&maintenant) & → donne l'adresse à remplir
*localtime(...) * → récupère la structure pointée
struct tm temps (c) structure passée par valeur (copie)
const char *texte pointeur vers texte en lecture seule
static const char *const noms[] tableau de noms constants et persistants
return noms[...]) renvoie l'adresse d'un nom valide
