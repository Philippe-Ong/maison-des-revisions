Réflexion et miroirs

À retenir

Formules

Loi de la réflexion : \theta_i = \theta_r (angles comptés par rapport à la normale, rayon incident, normale et rayon réfléchi dans un même plan).
Miroir plan : p = q — image virtuelle, symétrique, même grandeur, droite.
Miroir sphérique : \dfrac{1}{f} = \dfrac{1}{p} + \dfrac{1}{q}  et  G = -\dfrac{q}{p} = \dfrac{g'}{g}   avec f > 0 concave, f < 0 convexe, C = 2\,|f|.

Signes. p > 0 : objet réel, devant le miroir  \bullet q > 0 : image réelle, devant le miroir ; q < 0 : image virtuelle, derrière  \bullet G < 0 : image renversée ; G > 0 : droite  \bullet |G| > 1 : plus grande ; |G| < 1 : plus petite.

Rayons remarquables. Un rayon (1) parallèle à l'axe est réfléchi vers F ; (2) passant par F est réfléchi parallèlement à l'axe ; (3) passant par C est réfléchi sur lui-même ; (4) tombant au sommet est réfléchi symétriquement. Pour un miroir convexe (F et C derrière le miroir) : le rayon parallèle est réfléchi comme s'il venait de F, et le rayon dirigé vers F est réfléchi parallèlement à l'axe ; les rayons réfléchis divergent, on prolonge les tracés en pointillé en arrière du miroir pour trouver l'image. Deux rayons suffisent.

Miroir concave (f > 0)Miroir convexe (f < 0)
p < f : virtuelle, droite, plus grandetoujours virtuelle, droite, plus petite,
p = f : pas d'image (rayons réfléchis parallèles)située entre le sommet et F
f < p < C : réelle, renversée, plus grande|G| = \dfrac{|f|}{p - f} \to 1 quand p \to \infty
p = C : réelle, renversée, de même grandeur (G = -1)
p > C : réelle, renversée, plus petite
2

Réfraction

À retenir

Formules

Indice de réfraction : n = \dfrac{c}{v} (n sans unité ; c = 3 \cdot 10^{8}\ \text{m\,s}^{-1} ; plus n est grand, plus la lumière est lente).
Loi de Snell-Descartes : n_1 \sin\theta_1 = n_2 \sin\theta_2 (angles par rapport à la normale ; en passant vers un milieu plus réfringent, le rayon se rapproche de la normale).
Longueur d'onde et vitesse : c = \lambda f ; la fréquence ne change pas de milieu, donc \lambda_2 = \lambda_1 \dfrac{n_1}{n_2} et v_2 = \dfrac{c}{n_2}.
Angle limite (si n_1 > n_2) : \sin\theta_{\max} = \dfrac{n_2}{n_1} ; au-delà de \theta_{\max} il y a réflexion totale.

Indices usuels : vide 1 ; air 1{,}0003 \approx 1 ; eau 1{,}333 ; verre 1{,}5–1{,}7 ; zircon 1{,}9 ; diamant 2{,}4.

Fibre optique (cœur n_c, gaine n_g) : guidage par réflexion totale interne entre cœur et gaine, possible seulement si n_c > n_g (c'est l'angle limite entre ces deux milieux qui est déterminant). L'ouverture numérique vaut

\mathrm{ON} = \sin\alpha_{\max} = \sqrt{n_c^{2} - n_g^{2}} .

Temps de parcours minimal sur une longueur L (rayon le long de l'axe) : t = \dfrac{L\, n_c}{c}.

3

Lentilles minces

À retenir

Formule

Même équation que pour les miroirs : \dfrac{1}{f} = \dfrac{1}{p} + \dfrac{1}{q} et G = -\dfrac{q}{p} = \dfrac{g'}{g}, avec f > 0 convergente et f < 0 divergente. p > 0 objet réel, q > 0 image réelle (de l'autre côté de la lentille), q < 0 image virtuelle.

Rayons remarquables. Un rayon (1) parallèle à l'axe optique émerge en passant par F' ; (2) passant par F émerge parallèlement à l'axe ; (3) passant par le centre optique n'est pas dévié.

Lentille convergente (f > 0)Lentille divergente (f < 0)
p < f : virtuelle, droite, plus grandetoujours virtuelle, droite, plus petite,
p = f : pas d'image (faisceau émergent parallèle)entre la lentille et F
f < p < 2f : réelle, renversée, plus grande
p = 2f : réelle, renversée, même grandeur (G = -1)
p > 2f : réelle, renversée, plus petite

Deux lentilles successives (distantes de d) : l'image de la première sert d'objet à la seconde, donc p_2 = d - q_1 (p_2 < 0 : objet virtuel, autorisé) et le grandissement total est G = G_1 \cdot G_2. Lentilles accolées (d = 0) : \dfrac{1}{f} = \dfrac{1}{f_1} + \dfrac{1}{f_2}, soit f = \dfrac{f_1 f_2}{f_1 + f_2}.

Intuition

Exemple (exercice 28, recalculé)

f_1 = +15 cm, p_1 = 40 cm, f_2 = -10 cm à d = 10 cm. q_1 = 24 cm   \Rightarrow   p_2 = 10 - 24 = -14 cm (objet virtuel)   \Rightarrow   q_2 = -35 cm (image virtuelle) ; G = (-0{,}6)\times(-2{,}5) = 1{,}5. Clé de la série : [-35\ \text{cm}\ ; 1{,}5] — identique.
4

Marche à suivre pour un devoir

  1. Schéma à l'échelle : axe optique, sommet, F, C, objet fléché vers le haut (échelle 1:1 ou 1:2), miroir (ou lentille) en trait plein, hachures du côté non réfléchissant.
  2. Repérer f avec son signe — convertir d'abord : C = 2|f|, miroir concave \Rightarrow f > 0, convexe \Rightarrow f < 0.
  3. Calculer \dfrac{1}{q} = \dfrac{1}{f} - \dfrac{1}{p}, puis q.
  4. Grandissement : G = -\dfrac{q}{p} et g' = G\,g (|G| = taille, signe = sens).
  5. Conclure en trois mots : nature (q>0 réelle / q<0 virtuelle), sens (G>0 droite / G<0 renversée), taille (|G| comparé à 1).
  6. Vérifier : les rayons tracés doivent se croiser (ou leurs prolongements) au point trouvé par le calcul.

Pièges

Piège

À ne pas confondre

\bullet Les angles se mesurent toujours par rapport à la normale (à la surface pour un dioptre, à l'axe pour le sommet du miroir), jamais par rapport à la surface.
\bullet R (ou C) n'est pas f : convertir par f = \pm C/2 avant d'appliquer la formule (ex. 7 : C = 20 cm, miroir convexe \Rightarrow f = -10 cm).
\bullet q < 0 signifie image virtuelle (derrière le miroir / du même côté que l'objet pour une lentille), pas « pas d'image ». Le seul cas sans image est p = f.
\bullet Dans une association, l'image de la première lentille peut tomber derrière la seconde : p_2 = d - q_1 < 0 est légitime (objet virtuel), on garde le signe dans la formule.
\bullet Ne pas relier des points de mesure entre eux sur un graphique : on trace la courbe de régression (consignes de TP).
